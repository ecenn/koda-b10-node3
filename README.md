# Project: Calculator Lite

Aplikasi interaktif untuk melakukan perhitungan matematika sederhana.

## Capability
Memilih operasi matematika yang diinginkan:
- Penjumlahan (+)
- Pengurangan (-)
- Perkalian (×)
- Pembagian (÷)

Lalu memberikan hasil perhitungan dari input yang diberikan user.

## Requirements
- NodeJS LTS
- VSCode

## How to Run
1. Menginstal dependencies
```sh
npm install
```
2. Menjalankan project
```sh
npm run dev
```
